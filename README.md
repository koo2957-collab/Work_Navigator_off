# 업무 내비게이터 (배포용)

업무별 체크리스트·마감일·보고서·서식·법령 자료를 한곳에서 관리하는 **업무 도우미 프로그램**입니다.
설치나 서버 없이 `index.html`을 브라우저로 열면 바로 쓸 수 있고, 인터넷 연결 없이도 동작합니다.

- 현재 버전: **v1.2.0** (2026-10-08)
- 이 저장소는 **배포용**입니다. 사내 보안 정책에 따라 **외부 AI 연결 설정이 막혀 있습니다.**
  AI 연결을 시험하는 관리자용 버전은 별도 저장소 [ainav_final](https://github.com/koo2957-collab/ainav_final)에 있습니다.

## 시작하기

1. 이 저장소를 내려받습니다. (초록색 **Code** 버튼 → **Download ZIP** → 압축 풀기)
2. `index.html`과 `vendor` 폴더가 **같은 폴더 안에** 있는지 확인합니다.
3. `index.html`을 **Chrome** 또는 **Edge**로 엽니다.

> `vendor` 폴더가 없으면 글꼴, PDF 미리보기, Word 문서 읽기가 동작하지 않습니다.

## 파일 구성

| 파일 | 설명 |
| --- | --- |
| `index.html` | 프로그램 본체 (파일 하나로 동작) |
| `vendor/` | 프로그램이 사용하는 글꼴(Pretendard)과 PDF·Word 문서를 읽는 도구 |
| `사용설명서.md` | 기능별 사용 방법 |

## 내 자료는 어디에 저장되나요?

- 업무 자료는 프로그램 파일이 아니라 **브라우저 안의 저장 공간**에 저장됩니다.
  그래서 새 버전의 `index.html`로 바꿔도 자료는 그대로 남습니다.
- 다른 브라우저나 다른 PC에서는 자료가 보이지 않습니다. PC를 옮길 때는 **설정 → 백업 및 복원**에서 백업 파일을 만들어 옮기세요.
- 브라우저의 사용 기록·사이트 데이터를 지우면 자료가 사라질 수 있습니다. 정기적으로 백업하세요. 환경설정에서 백업 알림 주기(7일·30일·끄기)를 정할 수 있습니다.

## 주요 기능

- **업무 관리**: 상태 탭(전체·진행중·레퍼런스·처리완료·보관함), 폴더, 끌어다 놓기로 이동, 휴지통
- **체크리스트**: 「단계 + 할 일」 구조, 건너뛰기, 「해당 없음」 처리, 항목별 마감일
- **재사용 업무·레퍼런스**: 끝난 업무를 깨끗한 사본으로 등록해 두고, 다음에 복사하여 시작
- **보고서**: 작성·관리
- **서식·문서함**: 서식과 예시 공문 보관 (HWPX·PDF·Word 미리보기)
- **법령·매뉴얼 자료실**: 법령·지침 보관
- **알림**: 시작할 때 마감 임박 업무 안내, 헤더 종 아이콘의 알림센터
- **공유·내보내기·가져오기**: 진행 상태·조치결과·항목 메모·첨부까지 담은 업무 파일, 템플릿 패키지 (받는 쪽에서 「그대로 가져오기」·「복사하여 시작」 선택)
- **통계 대시보드**, **다크 / 라이트 모드**

> 이 배포용 버전에서는 AI 기능(AI 체크리스트·보고서·길잡이·업무파트너)과 AI 연결 설정을 쓸 수 없습니다.
> `사용설명서.md`의 「AI 모델 설정」「AI 기능」 항목은 AI 연결이 허용된 버전에 해당합니다.

## 알림센터 사용법

헤더 오른쪽의 종 아이콘을 누르면 알림 기록을 볼 수 있습니다.

- 종 아이콘의 **숫자**는 확인이 필요한 알림(마감 임박·경고·실패) 개수입니다. 완료 알림은 기록만 남고 숫자에 들어가지 않습니다.
- 알림을 누르면 관련 업무, 마감 임박 목록, 백업 설정 등으로 바로 이동합니다.
- 위쪽 버튼으로 **전체 / 안 읽음 / 업무·마감 / 시스템**을 골라 볼 수 있습니다.
- 「오늘의 업무 알림」과 「백업 리마인더」는 프로그램을 여러 번 열어도 **1건만 유지**되고, 내용이 바뀔 때만 다시 알려줍니다.

## 새 버전으로 바꾸기

1. 새 `index.html`(필요하면 `vendor` 폴더도)을 내려받아 기존 파일과 바꿉니다.
2. 같은 브라우저로 열면 기존 자료가 그대로 보입니다.

예전 버전 파일을 열면 프로그램이 경고를 띄웁니다. 바뀐 점은 **설정 → 버전 정보**에서 볼 수 있습니다.

## 관리자 참고

- 버전을 올릴 때는 `index.html` 안의 `APP_VERSION`, `APP_RELEASE_DATE`, `APP_RELEASE_NOTES` 세 가지만 고칩니다.
  - 기능 추가: 가운데 숫자를 올림 (1.1.0 → 1.2.0)
  - 오류 수정만: 끝 숫자를 올림 (1.1.0 → 1.1.1)
- 이 파일과 [ainav_final](https://github.com/koo2957-collab/ainav_final)의 `index.html`은 **AI 연결 설정 화면의 노출 여부만 다르고 나머지는 같습니다.** 기능을 고칠 때는 두 저장소에 똑같이 반영해야 합니다.
